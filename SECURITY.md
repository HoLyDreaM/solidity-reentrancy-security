# Güvenlik

Bu depo **eğitim ve demo** amaçlıdır.

- Üretim kullanımı, güvenlik denetimi (audit) geçirdiği veya gerçek fonları koruduğu **iddia edilmez**.
- `VulnerableBank` bilerek güvensiz bırakılmıştır; yalnızca laboratuvar / testnet senaryoları içindir.
- Gerçek cüzdan anahtarı, mnemonic veya API secret bu repoya konmamalıdır.
- Bulgu veya iyileştirme önerileri için [https://www.mehmet-ozdemir.com.tr/](https://www.mehmet-ozdemir.com.tr/) üzerinden iletişim kurun.

Üretim öncesi: CEI + guard + saldırgan kontrat testleri, statik analiz ve bağımsız inceleme önerilir.
